# M365 / Entra continuous compliance

> Baseline assessment and drift tracking for a Microsoft 365 test tenant.

**Status:** 🚧 In progress

## What it does
Runs CISA ScubaGear (SCuBA baselines) or Maester against a test tenant, maps results to CIS and NIST 800-53, and tracks configuration drift over time.

## Frameworks and controls
CISA SCuBA M365 baselines, CIS Microsoft 365 Benchmark, NIST 800-53 Rev 5

## Stack
PowerShell, ScubaGear / Maester, GitHub Actions
